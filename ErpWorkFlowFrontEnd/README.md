# ERP Workflow Frontend

React frontend for the ERP Workflow module.

## Stack

- React 18 + TypeScript + Vite
- React Router, Axios, TanStack React Query
- React Hook Form, Material UI, React Toastify

## Prerequisites

- Node.js 18+ (recommended: 20 via `.nvmrc`)
- Backend running at `http://localhost:8080`

## Setup

```bash
nvm use
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173). API requests are proxied to the backend at `/api`.

## Default Login

- Username: `admin`
- Password: `admin123`

## Build

```bash
npm run build
```
